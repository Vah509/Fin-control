# Текущее задание: правки интерфейса (по замечаниям владельца от 13.11.2026)

**Как пользоваться (всегда).** Это живое задание. Новый чат начинается так: «Прочитай docs/STATUS.md в репозитории Vah509/Fin-control (клонируй) и продолжи с первого неотмеченного пункта docs/CURRENT-TASK.md».
**Правило отметок.** Когда пункт реализован, в этом же ZIP его строка меняется с `[ ]` на `[x]` и получает дату и короткую пометку (что проверено). Частично сделанный пункт остаётся `[ ]` с пометкой «сделано: ..., осталось: ...». «Проверено владельцем на телефоне» отмечается только по его подтверждению. Когда все пункты закрыты, задание переносится в `docs/CHANGELOG.md` и файл заменяется следующим заданием.
Этапы идут по порядку, каждый обычно в отдельном чате и отдельном ZIP.

## Принятые решения (13.11.2026)

- Нижнее меню: Главная, Счета, Движения, Аналитика, Прочее. «Срез» переименован в «Аналитика», «Ещё» в «Прочее».
- Базовая валюта итогов выбирается в настройках: UAH, EUR, USD. По умолчанию EUR (настройка `base_currency` уже есть в `app_settings`, нужен только экран выбора).
- Курсы на главной: EUR/UAH, USD/UAH, EUR/USD (кросс-курсом). Автообновление при открытии приложения уже есть (monobank, запасной ПриватБанк, `src/core/fxUpdate.ts`); нужно показать курсы и изменение к предыдущему дню.
- Стрелки изменения курса привычные: рост зелёный ▲, падение красный ▼; в копейках («+0,12»).
- Главная настраивается в «Прочее → Настройки»: какие счета показывать (галочки), показывать ли общий итог, какие итоги по разделам, разделители, порядок блоков. По умолчанию итоги по разделам и общий итог идут в конце.
- Если перетаскивание всех блоков одним списком окажется слишком сложным, два экрана: «Что показывать» и «Порядок».
- Тестовые счета «пример» и «Тест2» пока остаются.
- Разделитель на экране «Счета» это не счёт и не раздел: полоса-пустышка без остатка, в расчётах не участвует, новых категорий нет.

## Этап 1. Навигация и экран «Счета»

- [ ] 1.1 Кнопка «назад» (Android и жест) возвращает на предыдущий экран по истории, а не закрывает приложение. Сейчас навигация это состояние `go(page)` в `src/ui/app.tsx` без истории браузера: нужны записи истории (history API). С корневой вкладки назад ведёт на «Главную», с «Главной» выход.
- [ ] 1.2 Нижнее меню: Главная, Счета, Движения, Аналитика, Прочее. Экран `snapshot` называется «Аналитика», `more` называется «Прочее».
- [ ] 1.3 Убрать верхние кнопки экрана «Счета» («+ Счёт», «+ Раздел», «Изменить порядок»). Вместо них плавающая кнопка-меню справа внизу над нижним меню: закреплена на экране, при прокрутке остаётся на месте. Пункты: новый счёт, новый раздел, изменить порядок. Кнопка «Готово» режима порядка остаётся доступной.
- [ ] 1.4 Убрать подпись «Нажмите на счёт, чтобы переименовать его…» внизу экрана «Счета» (подсказку режима порядка с ручкой ⠿ не трогать).
- [ ] 1.5 Карточка счёта (нажатие на счёт) упрощена: название и текущий остаток, «Ввести остаток», «В архив». Иконка-карандаш «Редактировать» открывает полную карточку (название, раздел, цвет, иконка, как сейчас в `Account.tsx`).
- [ ] 1.6 Экран «Закрытие периодов» показывает вверху, на какую дату период закрыт (или «не закрыт»).

## Этап 2. Разделители на экране «Счета»

- [ ] 2.1 В режиме порядка можно добавить разделитель (тонкая полоса) между счетами внутри раздела.
- [ ] 2.2 Разделитель перетаскивается так же, как счёт (за ручку ⠿) и удаляется.
- [ ] 2.3 Разделитель сохраняется (где хранить решить при работе, без бизнес-правил в базе), не влияет на остатки, итоги и срезы, попадает в выгрузку и загрузку JSON.

## Этап 3. Настройки и итоги по разделам

- [ ] 3.1 «Прочее → Настройки» (новый экран).
- [ ] 3.2 Настройка «Базовая валюта» UAH/EUR/USD (по умолчанию EUR); запись настройки только владельцем, через ядро.
- [ ] 3.3 Все итоги и «≈» у счетов пересчитываются в выбранную базовую валюту; при смене базовой валюты недостающие курсы запрашиваются автообновлением.
- [ ] 3.4 На экране «Счета» напротив названия каждого раздела итого по разделу в базовой валюте; если нет курса, «нет курса», а не неверная сумма.

## Этап 4. Курсы на главной

- [ ] 4.0 Проверка владельцем: на Главной появляется «Курсы на сегодня обновлены (monobank)» (STATUS, п. 00). Если банки блокируют запрос (CORS), сначала Cloudflare Worker-посредник.
- [ ] 4.1 Ядро считает три пары EUR/UAH, USD/UAH, EUR/USD из сохранённых курсов (прямая, обратная, кросс) на сегодня и на предыдущую дату с курсом.
- [ ] 4.2 Блок курсов на главной: значение, изменение к предыдущему дню с копейками и стрелкой (▲ зелёная, ▼ красная). Если предыдущего курса нет, «—».
- [ ] 4.3 Тесты ядра на выдуманных курсах (рост, падение, нет предыдущего, кросс-курс).

## Этап 5. Главный экран и его настройка

- [ ] 5.1 С главной убраны «Ввести остаток» и «Срез на дату» (срез живёт в «Аналитике», ввод остатка в карточке счёта).
- [ ] 5.2 Главная показывает курсы (этап 4) и выбранные блоки в заданном порядке; по умолчанию: курсы, затем счета, в конце итоги по разделам и общий итог.
- [ ] 5.3 Настройки главной (`Прочее → Настройки`): галочки счетов, общий итог вкл/выкл, итоги по разделам вкл/выкл, разделители вкл/выкл.
- [ ] 5.4 Порядок блоков главной задаётся в настройках перетаскиванием (или вторым экраном «Порядок», если одним списком слишком сложно).
- [ ] 5.5 Настройки главной хранятся в `app_settings` (ключи решить при работе) и попадают в выгрузку JSON.

## Зависимости

1 → 2 → 3 → 4 → 5. Этапу 3 нужны настройки для этапов 4 и 5; этап 5 использует курсы этапа 4.

## Открытые вопросы владельцу

- На главной показывать сохранённый консервативный курс (банк продаёт базовую валюту, «бери меньше», решение 13.11.2026) или средний курс банка? Предложение: показывать сохранённый, чтобы цифры на главной совпадали с итогами.
