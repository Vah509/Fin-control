# Текущее задание: выбирает владелец в начале нового чата

**Как пользоваться (всегда).** Новый чат начинается так: «Прочитай docs/STATUS.md в репозитории Vah509/Fin-control (клонируй) и продолжи с первого неотмеченного пункта docs/CURRENT-TASK.md».
**Правило отметок.** Когда пункт реализован, в этом же ZIP его строка меняется с `[ ]` на `[x]` и получает дату и короткую пометку (что проверено). Частично сделанный пункт остаётся `[ ]` с пометкой «сделано: ..., осталось: ...». «Проверено владельцем на телефоне» отмечается только по его подтверждению. Когда все пункты закрыты, задание переносится в `docs/CHANGELOG.md` и файл заменяется следующим.

## Что выбрать дальше (владелец выбирает в новом чате; Claude до выбора ничего не пишет)

Первый вопрос нового чата: «С чего начать?» Варианты (подробно в `docs/ROADMAP.md`):
1. **Ввод вручную (шаг 5.1)**: приход и расход на счёт, наличные за 2 шага (сумма, затем плитки тегов), ярлыки PWA. Нужны начальные теги (черновик готовит Claude). Предложение Claude: начать с этого, это даёт данные для всего остального.
2. **Экран «Движения» (коррекция 2.1)**: фильтры по счёту, периоду, типу; карточка операции; правка комментария, даты, тега; удаление и восстановление; подгрузка старых записей.
3. **Выгрузка (4.1-4.2)**: шифрование файла паролем, «Поделиться», автокопия и напоминание.

Открытые вопросы владельцу: `docs/DECISIONS.md`, раздел 3 (в частности `dedupe_hash`, ключ шифрования, строгое закрытие, карточки или иконки).
