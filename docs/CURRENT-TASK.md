# Текущее задание: импорт выписок ПриватБанка (старт в новом чате)

**Как пользоваться (всегда).** Новый чат начинается так: «Прочитай docs/STATUS.md в репозитории Vah509/Fin-control (клонируй) и продолжи с первого неотмеченного пункта docs/CURRENT-TASK.md».
**Правило отметок.** Когда пункт реализован, в этом же ZIP его строка меняется с `[ ]` на `[x]` и получает дату и короткую пометку (что проверено). Частично сделанный пункт остаётся `[ ]` с пометкой «сделано: ..., осталось: ...». «Проверено владельцем на телефоне» отмечается только по его подтверждению.

## Решение владельца 14.11-15.11.2026
Начинаем с реального примера: выписка ПриватБанка получена 15.11.2026 (xlsx, три карты 0444, 0380, 4402, 25.08-25.10.2026). По ней согласован **алгоритм загрузки выписок через задания на импорт**: `docs/IMPORT-DESIGN.md` (читать целиком перед работой). Коротко: приложение готовит пакет (счета, признаки, контрагенты, введённые остатки) → чат вне проекта разбирает выписку в `import.json` → приложение проверяет, показывает расхождения в трёх разделах, владелец решает → загрузка в базу. Чат не определяет «внутренние переводы»: все строки `income`/`expense`.
