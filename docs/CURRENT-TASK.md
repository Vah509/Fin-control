# Текущее задание (ветка `statement-xlsx`): разбор выписок в стандартный XLSX

**Как пользоваться (всегда).** Новый чат начинается так: «Прочитай docs/STATUS.md в репозитории Vah509/Fin-control (клонируй, ветка statement-xlsx) и продолжи с первого неотмеченного пункта docs/CURRENT-TASK.md».
**Правило отметок.** Реализованный пункт меняется с `[ ]` на `[x]` с датой и пометкой, что проверено. Частично сделанный остаётся `[ ]` с пометкой «сделано: ..., осталось: ...». «Проверено владельцем на телефоне» отмечается только по его подтверждению.
**Описание, решения, формат, шаблоны:** `docs/STATEMENT-XLSX.md` (читать целиком). Прежнее задание (учёт остатками, пункты 5-6 ждут проверки владельцем): `docs/TASK-BALANCES.md`.
**Правила ветки:** ZIP кладётся в `ai-updates/` в ветке `statement-xlsx`; миграции только добавляющие; реальные выписки в репозиторий не класть, тесты на выдуманных данных.
