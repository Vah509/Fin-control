# Текущее задание: правки интерфейса (по замечаниям владельца от 13.11.2026)

**Как пользоваться (всегда).** Это живое задание. Новый чат начинается так: «Прочитай docs/STATUS.md в репозитории Vah509/Fin-control (клонируй) и продолжи с первого неотмеченного пункта docs/CURRENT-TASK.md».
**Правило отметок.** Когда пункт реализован, в этом же ZIP его строка меняется с `[ ]` на `[x]` и получает дату и короткую пометку (что проверено). Частично сделанный пункт остаётся `[ ]` с пометкой «сделано: ..., осталось: ...». «Проверено владельцем на телефоне» отмечается только по его подтверждению. Когда все пункты закрыты, задание переносится в `docs/CHANGELOG.md` и файл заменяется следующим заданием.
Этапы идут по порядку, каждый обычно в отдельном чате и отдельном ZIP.

## Принятые решения (13.11.2026)

- Нижнее меню: Главная, Счета, Движения, Аналитика, Прочее. «Срез» переименован в «Аналитика», «Ещё» в «Прочее».
- Базовая валюта итогов выбирается в настройках: UAH, EUR, USD. По умолчанию EUR (настройка `base_currency` уже есть в `app_settings`, нужен только экран выбора).
- Курсы на главной: EUR/UAH, USD/UAH, EUR/USD (кросс-курсом). Автообновление при открытии приложения уже есть (monobank, запасной ПриватБанк, `src/core/fxUpdate.ts`); нужно показать курсы и изменение к предыдущему дню.
- Стрелки изменения курса привычные: рост зелёный ▲, падение красный ▼; в копейках («+0,12»).
- Главная настраивается в «Прочее → Настройки»: какие счета показывать (галочки), показывать ли общий итог, какие итоги по разделам, разделители, порядок блоков. По умолчанию итоги по разделам и общий итог идут в конце.
- Если перетаскивание всех блоков одним списком окажется слишком сложным, два экрана: «Что показывать» и «Порядок».
- Тестовые счета «пример» и «Тест2» пока остаются.
- Разделитель на экране «Счета» это не счёт и не раздел: полоса-пустышка без остатка, в расчётах не участвует, новых категорий нет.
