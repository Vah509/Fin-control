**Правило отметок.** Реализованный пункт меняется с `[ ]` на `[x]` с датой и пометкой, что проверено. Частично сделанный остаётся `[ ]` с пометкой «сделано: ..., осталось: ...». «Проверено владельцем на телефоне» отмечается только по его подтверждению.
