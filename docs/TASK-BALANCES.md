# Текущее задание: учёт остатками (раз в месяц ввод остатков по счетам)

**Как пользоваться (всегда).** Новый чат начинается так: «Прочитай docs/STATUS.md в репозитории Vah509/Fin-control (клонируй) и продолжи с первого неотмеченного пункта docs/CURRENT-TASK.md».
**Правило отметок.** Реализованный пункт меняется с `[ ]` на `[x]` с датой и пометкой, что проверено. Частично сделанный остаётся `[ ]` с пометкой «сделано: ..., осталось: ...». «Проверено владельцем на телефоне» отмечается только по его подтверждению.

## Решение владельца 17.11.2026
Загрузка движений из выписок поставлена на паузу (`docs/TASK-IMPORT-PAUSED.md`). Второй вид учёта: владелец вводит остатки по счетам на дату (например раз в месяц), без движений.
- **Экран «Ввод остатков»**: Прочее → «Ввод остатков». Список активных счетов по разделам; у каждого счёта дата последнего введённого остатка и его сумма («нет данных», если не вводился); поля «Дата» и «Остаток» и кнопка «Сохранить» у каждого счёта. Вводить можно поэтапно, по одному счёту.
- **Запись**: только контрольная точка нового вида `entered`. Корректировки и операции НЕ создаются. Точки `entered` не сверяются с расчётом по движениям (нет расхождений, не мешают закрытию периода), форма «Ввод остатка» их не видит.
- **Главная**: переключатель «Движения / Остатки». «Движения» как раньше. «Остатки»: те же счета, выбранные в настройках Главной, но суммы берутся из последних введённых остатков (по курсу на сегодня в базовую валюту); счёт без остатка показывается как «нет данных» и в итоги не входит; блока «Неучтённое» нет.
- **Не делаем**: срез на дату по остаткам в «Аналитике» (там всё как есть), массовый ввод по всем счетам одним экраном.
