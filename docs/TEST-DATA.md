# Тестовые данные в Test-fin-cintrol (песочница)

Правило: тестовые счета имеют ключ `test-…` (сейчас `test-vypis`, название «ТЕСТ-выписка (удалить)», EUR, признак номера с последними цифрами 9001, доступ владельца). Тестовые операции живут только на них. Рабочий проект Fin-control (на паузе) этих данных не содержит. SQL выполняет Claude через MCP по слову владельца («сбрось тест» или «удали тест»); миграции для этого не нужны (миграции только для схемы).

Тестовая выписка: файл `test-vypis-SPACE-9001.pdf` (выдуманный, генерируется по фикстуре `tests/statements/slspFixture.ts`): 3 операции (−10,00 от 03.09.2026, −20,00 от 05.09, +500,00 от 06.09), остаток 1000,00 → 1470,00.

## Исходное состояние теста (сброс)
В базе у `test-vypis`: −20,00 (05.09.2026) и +500,00 (06.09.2026) совпадают с выпиской, −7,77 (10.09.2026) лишняя. Ожидается: строка 1 только «В выписке», строки 2-3 в обеих колонках, внизу жёлтая −7,77, проблем 1 («есть в базе, нет в выписке»).

Сброс: удалить операции счёта `test-vypis` и вставить три исходные (booked_at 2026-09-05/06/10 10:00Z, source manual, комментарии «тест: …»). Чтобы проверить запись по «Готово», удалить лишнюю −7,77 (проблем станет 0).

## Полное удаление
Удалить по счетам с ключом `test-%`: операции (в том числе парные записи переводов на других счетах с тем же `transfer_id`), признаки (`account_identifiers`), доступы (`account_access`), сам счёт. Задачи выписок (`statement_tasks`) удаляются из приложения кнопкой «Удалить загрузку».

## Текущее состояние теста (22.11.2026, после проверки записи)
Лишняя операция −7,77 удалена. Операция −10,00 от 03.09.2026 записана из выписки по «Готово» (`source = import`). Теперь у `test-vypis` три операции, совпадающие с тестовой выпиской (−10,00, −20,00, +500,00). Загрузка того же PDF новой задачей должна дать плюсы в «В выписке» и «В базе» по всем трём строкам и 0 проблем. Чтобы повторить тест записи: сброс (операции счёта удалить, вставить −20,00 и +500,00 как «исходные»), или вернуть лишнюю −7,77 для проверки проблемы.

## Тестовые выписки для экрана решения проблем (22.11.2026, версия 0.2.20)
Пять выдуманных PDF SPACE (данные в `tests/statements/scenarios.ts`, проверка разбора и сверки в `scenarios.test.ts`; PDF рисуются из этих данных, в репозиторий не кладутся).
