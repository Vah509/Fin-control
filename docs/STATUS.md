# Fin-control: состояние проекта (обновлено 17 ноября 2026)

**Точка входа для любого нового чата.** Читать целиком, затем файлы из раздела 9 по необходимости.
Где этот файл и документы `docs/` расходятся с брифом v2, дополнением v3 (файлы проекта Claude) и `db-schema-iteration-1.md`, **верны `docs/`**. Актуальная схема базы: `docs/DATA-MODEL.md` и `supabase/migrations/`.

**Версия приложения: 0.2.7** (видна вверху Главной). Повышается в каждом ZIP (`docs/WORKFLOW.md`).

## 1. Что это

Личное приложение учёта денег в разных местах, странах и валютах. Главный сценарий: срез остатков на выбранную дату. Второй: движения (откуда пришло, куда ушло).
Владелец: Вахтанг (Братислава). Работает **с телефона** (git и компьютера нет), общается по-русски, коротко.

## 2. Как продолжить в новом чате

Первая фраза владельца: «Прочитай docs/STATUS.md в репозитории Vah509/Fin-control (клонируй) и продолжи с первого неотмеченного пункта docs/CURRENT-TASK.md». В `CURRENT-TASK.md` лежит текущее задание с пунктами.
Что делает Claude: клонирует `https://github.com/Vah509/Fin-control.git`, читает этот файл, `docs/WORKFLOW.md` (правила работы и состав ZIP) и нужные документы, запускает `npm ci && npm run build && npx vitest run`, сверяет результат с разделом 4. Если не сходится, сначала правит документацию и сообщает владельцу.

## 3. Репозиторий

- Адрес: https://github.com/Vah509/Fin-control. Стек: Vite + React + TypeScript, Supabase (Postgres, Auth, RLS), Cloudflare Pages.
- Проверка: `npm ci`, `npm run build` (включает `tsc`), `npx vitest run` (**189 тестов**, 22 файла; на 17.11.2026 всё зелёное). `npm run test:supabase` против живой базы нужны переменные `TEST_SUPABASE_URL`, `TEST_SUPABASE_ANON_KEY`, `TEST_USER_EMAIL`, `TEST_USER_PASSWORD`; пока не запускался.
- Cloudflare Pages: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (publishable-ключ). Сервисный ключ нигде не используется.
- Курсы: везде средний курс банка (`DECISIONS.md`, 14.11.2026). Тестовый проект Supabase: Test-fin-cintrol (Ireland). Рабочего проекта нет. В тестовой базе загружен seed (20 счетов, 45 контрагентов, 18 тегов в 10 группах, 2 стартовые корректировки). Репозиторий публичный: seed и личные данные в него не кладутся.
- Доставка изменений, состав ZIP и правила актуальности документов: `docs/WORKFLOW.md`.

## 5. Что нужно владельцу сразу

**17.11.2026 (версия 0.2.7, учёт остатками):** 1) выполнить в SQL Editor тестового Supabase миграцию `supabase/migrations/20261117100000_iteration7_entered_balances.sql` (две команды `alter table`, безопасна для повтора); 2) убедиться, что вверху Главной версия 0.2.7; 3) Прочее → «Ввод остатков»: ввести дату и остаток по 1-2 счетам, «Сохранить»; 4) на Главной переключатель «Остатки»: суммы из введённых остатков, у счетов без ввода «нет данных»; вкладка «Движения» не должна измениться. Если что-то не так, прислать текст сообщения или скриншот. Загрузка выписок на паузе (`docs/TASK-IMPORT-PAUSED.md`).

**16.11.2026 (версия 0.2.3):** 1) выполнить в SQL Editor тестового Supabase миграцию `supabase/migrations/20261115200000_iteration6_import_review.sql` (одна строка `alter table`, безопасна для повтора); 2) убедиться, что вверху Главной версия 0.2.2; 3) Прочее → «Загрузка выписок» → задание 63147155 (или новое) → «Ответ чата»: «Выбрать файл» (JSON от чата), «Загрузить»; на карточках карт «Привязать» счёт, решить остаток на начало (корректировка), контрагентов (по желанию), «Проверить», «Загрузить в базу». Если что-то не так, прислать текст сообщения или скриншот. Загрузку можно откатить кнопкой «Откатить загрузку».

**15.11.2026:** миграция `import_jobs` применена. Проверить на телефоне новый двухшаговый экран: Прочее → «Загрузка выписок» → «Новое задание» (шаг 1 галочки, шаг 2 остатки, «Сформировать файл», затем «Поделиться»).
